# Contributing Guide

We welcome contributions to TrueStream! To contribute:

## Code Style
- **Flutter:** Adhere to the official Dart style guide and linter settings.
- **Python:** Use PEP 8 formatting standards.

## Development Workflow
1. Fork the repository and create your feature branch.
2. Ensure all changes are verified and do not break compilation.
3. Write clean commit messages describing the change logically.
4. Submit a Pull Request targeting the `main` branch.
